# Frequências, Rankings e Série Temporal — PRF 2025

## Objetivo

Esta atividade faz parte da **Unidade 05 — Analytics PRF**, pertencente ao módulo de **Data Analytics e EDA**.

O objetivo é aplicar técnicas de análise exploratória de dados utilizando frequências, rankings e análises temporais sobre os acidentes registrados pela **Polícia Rodoviária Federal (PRF) em 2025**.

A análise busca identificar padrões relacionados à ocorrência dos acidentes, considerando volume de registros e indicadores de gravidade.

---

# Metodologia

Foram realizadas análises utilizando agrupamentos, contagens e rankings para comparar diferentes dimensões dos acidentes.

Os indicadores foram analisados considerando:

- Quantidade total de acidentes;
- Quantidade de acidentes fatais;
- Percentual de acidentes fatais;
- Comparação entre categorias;
- Identificação dos maiores e menores índices.

A análise considera que frequência e gravidade são indicadores diferentes. Uma categoria pode apresentar grande quantidade de ocorrências, mas menor proporção de acidentes fatais, enquanto outra pode apresentar menor volume e maior severidade.
