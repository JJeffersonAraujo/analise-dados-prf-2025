# Dataset — PRF 2025

Esta pasta contém o conjunto de dados utilizado nas atividades desenvolvidas ao longo do projeto.

## Fonte dos dados

Dados públicos de acidentes rodoviários registrados pela **Polícia Rodoviária Federal (PRF)** referentes ao ano de **2025**.

## Utilização

O dataset é utilizado nas diferentes unidades do projeto:

- Unidade 01 — Fundamentos de Excel
- Unidade 02 — Análise e Visualização com Excel
- Unidade 03 — SQL com SQLite
- Unidade 04 — Preparação dos Dados com Python

A centralização do arquivo nesta pasta evita duplicação do conjunto de dados entre as diferentes atividades.
